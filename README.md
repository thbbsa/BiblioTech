📖 BiblioTech

Sistema de gerenciamento de biblioteca desenvolvido em Java puro, rodando via terminal, aplicando conceitos de Orientação a Objetos.

## 🚀 Tecnologias

- Java

## 📋 Pré-requisitos

- JDK instalado

## ⚙️ Instalação

```bash
git clone https://github.com/thbbsa/BiblioTech.git
cd BiblioTech
```

## ▶️ Como rodar

Compile e execute a classe principal pelo terminal:

```bash
javac Bibliotech/*.java
java Bibliotech.NomeDaClassePrincipal
```

Ou rode diretamente pela sua IDE (IntelliJ, Eclipse, VS Code).

## ✨ Funcionalidades

- Cadastro e gerenciamento de livros
- Cadastro de usuários/leitores
- Controle de empréstimos e devoluções

## 📁 Estrutura do projeto
└── Bibliotech/    → código-fonte do sistema

## 📝 Sobre

Projeto desenvolvido como exercício acadêmico, aplicando princípios de Programação Orientada a Objetos (POO) em uma aplicação de terminal, com dados mantidos em memória durante a execução.
